## 参数说明

| 参数 | 范围 | 调节效果 |
|---|---|---|
| 基础频率 | 1~16（整数） | 一屏内噪声"格子"数量；越大细节越密、纹理越碎 |
| 迭代层数 octaves | 1~8 | 分形叠加层数（增益 0.5、lacunarity 2 内定）；越大层次越丰富、越像自然云/地表 |
| 对比度 | 0.5~3.0 | 拉开或压平明暗分布；要"遥感感"调 1.2~1.8 |
| 配色方案 | 云层 / 荒漠 / 海洋 / 岩石 / 灰度地形 | 多停靠点线性插值上色，按钮色带即真实色卡 |
| 随机种子 | 0 ~ 4294967295 | 同种子 + 同参数 = 逐像素一致的同一张纹理 |
| 画布尺寸 | 512 / 1024 | 预览与导出分辨率 |
| 无缝拼接 | 开 / 关 | 开启后四边连续，导出 PNG 可四方平铺 |

按钮：

- **一键重新生成**：换一个随机种子并重渲染（"抽卡"，抽到满意为止）
- **随机**：只换种子（效果同上，即时反馈）
- **导出 PNG（当前配色）**：`canvas.toBlob` 触发下载，文件名含种子与参数摘要，如
  `perlin_cloud_seed20260829_f4_o5_c1.00_512px_seamless.png`
- **导出灰度 PNG（地形高度图）**：忽略当前配色，输出黑→白高度图（R=G=B），文件名带 `heightmap`

## 无缝模式一句话原理

开启后把噪声采样坐标对周期取模（周期 = 基础频率 × 2^层号，各层同步翻倍），格点索引在图像边界绕回，
使 noise(u) ≡ noise(u + 周期)，纹理四方连续；关闭时边界自由延展，平铺会出现接缝。
因此**无缝模式下频率取整**——这是周期采样成立的数学前提。

## 三个典型用途

1. **遥感模拟纹理**：云层/荒漠配色 + 频率 2~6 + 层数 4~6，似大尺度地物斑块，可当合成影像底图、
   分类蒙版或演示素材（同款思路见工作区 S2 CVA 变化检测项目的合成时序）。
2. **可平铺背景图**：无缝模式导出，四方连续，网页/桌面/游戏背景直接平铺。
3. **简易地形高度图**：配色切"灰度地形"或直接"导出灰度 PNG"，黑=低 白=高，
   可喂给 Cesium / Three.js 当位移/高度贴图做快速地形原型。

## 种子复现

导出文件名里记录了 `seed / f(频率) / o(层数) / c(对比度) / 尺寸 / seamless`，回填面板即可逐像素复现同一张纹理。
