Perlin 噪声纹理工坊

原生 JS Canvas · 零依赖零 CDN · 无缝平铺 · 遥感模拟纹理 / 背景图 / 灰度地形
您的浏览器不支持 Canvas
滑块改动 150ms 防抖即时生效；调种子与参数即"抽卡"，抽到满意的直接导出。
用途一 · 遥感模拟纹理云层/荒漠配色 + 频率 2~6 + 层数 4~6，似大尺度地物斑块，可当合成影像底图或分类蒙版。
用途二 · 可平铺背景图勾选"无缝拼接"后导出 PNG，四方连续无接缝，网页 / 桌面 / 游戏背景直接平铺。
用途三 · 简易地形高度图切"灰度地形"或点"导出灰度 PNG"，黑=低 白=高，可喂 Cesium / Three.js 当位移贴图。
配色方案
基础频率（1~16）4
迭代层数 octaves（1~8）5
对比度（0.5~3.0）1.00
随机种子（同种子同参数逐像素可复现）
画布尺寸
玩法：右侧调频率 / 层数 / 对比度与配色即时预览，点"一键重新生成"换种子抽卡；无缝模式下导出的 PNG 四方连续可直接平铺； "导出灰度 PNG"所得黑-白图（R=G=B）可直接当简易地形高度图（DEM）使用。同一种子 + 同一组参数 = 逐像素一致的同一张纹理。 自动化自测：node test\test.js（确定性 / 周期无缝 / 边界健壮 / 灰度 / 性能全绿后交付，报告见 report/自测报告.md）。
