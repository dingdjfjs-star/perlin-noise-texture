## 关于"首末列差 < 0.02"判据的口径说明

- 首列 vs 末列是**相邻像素**，其差值=跨缝处的空间梯度，天然随频率线性增大：freq=2/oct=4 时 0.0167（达标），
  freq=8/oct=8 时 0.0746（相邻像素差大≠有接缝）。
- 无缝的**数学判据**是第 5 节的周期性等式：noise(u) ≡ noise(u+P)（实测 ≤ 4.04e-13，浮点精度内恒等），
  即"下一块砖的第一列 = 本块第一列"，平铺无接缝由此保证。
- 关闭无缝时首末列差 0.3204（约 19 倍于无缝模式），且开/关渲染场最大差 0.441（集中于边缘带），
  证明开关真实生效。

## 迭代留痕

1. **首轮 42/43**：唯一失败为总行数 580 < 600 目标下限。处置：给页面补"三大用途速查卡"（三张卡片，
   内容即 README 的三用途结论）与页脚自测提示行，属于有效信息而非凑行；复测 604 行，43/43 全绿。
2. 无缝实现选型：频率滑块取整数步长（1~16）——周期采样要求图像跨度恰为一个整数周期，
   无缝时各层周期 = 频率 × 2^层号（最大 2048），置换表值域取 4096、双倍展开至 8192 以保证
   `perm[perm[x]+y]` 二级索引在最大周期下不越界。
3. 渲染管线：噪声场（种子/频率/层数/尺寸/无缝 变动才重算，含 stretch01 归一化）→ 对比度重映射（轻量）
   → 256 级配色 LUT 查表上色，拖滑块不重算噪声，交互丝滑。
